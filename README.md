# Mon Prochain Bus

A modern transit application that helps users track their favorite bus/train stops and view upcoming passages in real-time.

## Features

- View next passages for transit stops
- Add and manage favorite stops
- Dark/Light theme support
- Real-time updates
- Responsive design

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- PWA support

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- pnpm (recommended) or npm
- RATP API Key (get it from [IDFM API Portal](https://prim.iledefrance-mobilites.fr/fr/apis))

### Installation

1. Clone the repository

```bash
git clone [your-repo-url]
```

2. Install dependencies

```bash
pnpm install
```

3. Create a `.env` file in the root directory and add your API key:

4. Start the development server

```bash
pnpm run dev
```
